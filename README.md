# 🐒 Шимпанзе: побег из зоопарка

Небольшая изометрическая игра в браузере. Ты — шимпанзе в вольере: ешь бананы, тренируешься, устраиваешь шоу для публики, решаешь головоломки, воруешь у смотрителя ключ — и сбегаешь на волю.

**▶ Играть: https://zholudmaxim91.github.io/chimp-zoo-escape/**

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` / стрелки | идти |
| `E` или `Пробел` | действие с тем, что рядом |
| `F` | бросить 💩 в ближайшего зрителя |
| `Esc` | отменить головоломку |

В игре есть короткое обучение (6 шагов), его можно пропустить или запустить заново кнопкой «🎓 Обучение».

## Что внутри

- 4 характеристики: 💪 Сила, 🤸 Ловкость, 🧠 Интеллект, 🎭 Харизма (до 5 уровня)
- банановые деревья, лазалка, шина-качели, ящик-головоломка, сцена с публикой, камни с находками, пруд
- смотритель с ключом: ключ можно стащить, лучше заходя сзади
- броски 💩 в посетителей: разные реакции, комбо, риск, что заметит смотритель
- 9 заданий и 12 достижений
- побег: ключ + сумма уровней 10, затем к воротам

## Запуск у себя

Скачай `index.html` и открой двойным кликом. Больше ничего не нужно.

## Технологии

Один файл: HTML + Canvas + чистый JavaScript, без библиотек и картинок: вся графика рисуется кодом.
