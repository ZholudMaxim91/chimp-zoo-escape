# 🐒 Шимпанзе: побег из зоопарка

Пиксельная изометрическая игра в браузере. Ты — шимпанзе в огромном вольере с ярусами: прокачивайся, перехитри смотрителя и сбеги на волю.

**▶ Играть: https://zholudmaxim91.github.io/chimp-zoo-escape/**
(первая, простая версия осталась здесь: https://zholudmaxim91.github.io/chimp-zoo-escape/v1/)

## Управление

| Клавиша / мышь | Действие |
|---|---|
| `W` `A` `S` `D` | идти (`Shift` — бег, `C` — красться) |
| `Пробел` | прыжок: так забираешься по ярусам |
| `E` | действие с тем, что рядом · `R` — съесть банан |
| **Мышь** | прицел, `ЛКМ` — применить выбранный инструмент |
| `ПКМ` / `Q` | громкий крик (зовёт публику, раздражает смотрителя) |
| `1`–`6` / колесо | выбор инструмента |

## Инструменты

1. 💩 бросок · 2. 🍌 банан (приманка для зверей, подножка смотрителю) · 3. 🪨 камень (гонг, попугаи)
4. 🥢 палка (термитники, клады, шкафчик в сторожке) · 5. 🪢 лиана (на уступы выше; нужна Ловкость 2) · 6. 💦 вода (набирается у пруда)

## Что в игре

- Мир 40×40 клеток с ярусами до 5 уровней: гора со склоном и обрывами, домик на вершине, мостки на сваях, пруд, лес, песочница, сцена, сторожка.
- Животные: друзья-шимпанзе (дружба за бананы, «подсадка»), горилла (отнимает бананы, её можно отвлечь), черепахи-батуты, попугаи.
- Смотритель с полем зрения: можно красться, отвлекать гонгом, ронять бананом. Ключ — украсть, взломать шкафчик или получить после подножки.
- Инструменты, раскопки, сундуки, наковальня для орехов, барабаны, ящик-головоломка, сцена с публикой.
- 12 заданий, 15 достижений, обучение (6 шагов).
- Каждый мир строится из **сида**: одинаковый сид — одинаковый мир.

## Сетевая игра

1. В меню войди в профиль (имя и пароль хранятся только на твоём устройстве).
2. Один игрок нажимает «Создать сессию по сиду» — он хост. Остальные вводят **тот же сид** и жмут «Войти в сессию».
3. До 6 игроков в одном мире: общие животные, смотритель, зрители, ключ и ворота. Побег — у каждого свой.
4. **Дуэль говном:** подойди к игроку, нажми E; соперник принимает клавишей Y. До 5 попаданий, победитель +60 очков.

Связь идёт напрямую между браузерами (WebRTC). Хост должен оставаться в игре. В некоторых сетях прямое соединение может не установиться.

## Запуск у себя

Скачай репозиторий и открой `index.html` двойным кликом.

## Технологии

HTML + Canvas + чистый JavaScript, без библиотек и картинок: пиксель-арт спрайты рисуются кодом при запуске.
Код разложен по файлам в папке `js/`: мир, спрайты, отрисовка, существа, игра.
